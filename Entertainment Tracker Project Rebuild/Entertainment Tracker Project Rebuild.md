
# Tech Stack

1. Language: OpenJDK 25.0.3 & GraalVM
2. UI Library: JavaFX 25.0.3
3. Build Tool: Apache Maven 3.9.6
4. Logging Library: Apache Log4J 2.25.3
5. Database: Nitrite
6. Indexer: Apache Lucene
7. Platform (x86):
	1. Win11: .msi & .exe
	2. macOS: .dmg
	3. Debian Linux: .deb
	4. Red Hat Linux: .rpm
8. Version Control System: Git 2.4.0.windows.1
9. Git Repository Hosting Platform: GitHub
10. Annotations Library: Lombok 1.18.32
